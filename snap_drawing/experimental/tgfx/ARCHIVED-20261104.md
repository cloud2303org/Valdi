# Archived TGFX experiment

Status: archived on November 4, 2026 at the user's request. Keep this work on
`experiment/tgfx-prototype-20261104`; do not merge it into the normal runtime
branch or change the application pin.

The application continues to use the existing Skia runtime from framework
revision `51cec8ae3645c7e778c9f36fbe4b3bffba1ccddf`. This experimental branch
also keeps Skia as its default; TGFX requires the explicit
`--define=snap_drawing_backend=tgfx` selection.

## What is preserved

- The complete guarded SnapDrawing/Valdi source port, dependency preparation
  tools, native regression suites, isolated Hermes acceptance hosts, and
  shared Release performance benchmarks.
- The earlier standalone vector prototype and its history.
- Current cumulative TGFX and ThorVG source patches, exact upstream pins,
  changed-file hashes, and local prepared-profile identities under
  `full/archive/20261104/vendor/`.
- Final performance/size results and the reviewed raw-report bundle under
  `full/archive/20261104/performance/`.
- Historical source snapshots, regression fixtures, licenses, and provenance.
  Files documenting earlier failures or source-only handoffs remain historical
  evidence; see the final validation and performance reports for later results.

The performance report is
[`full/performance/RESULTS-20261104.md`](full/performance/RESULTS-20261104.md).
The final real-app acceptance record is
[`full/app/VALIDATION-20261104.md`](full/app/VALIDATION-20261104.md).

## Why it is not being adopted

The measured Android runtime shrank by 7.42%, and the minimal Release benchmark
APK shrank by 4.97%. The current implementation regressed in every measured
Android GPU/readback and managed-bitmap scene. iOS simulator results were mixed,
with larger binaries and substantial timing variability. Lottie remains
enabled. No presented-FPS, physical-phone power, or iOS device-shipping-size
benefit was established.

## Recovering the source experiment

Check out this branch and obtain the exact TGFX and ThorVG revisions in
`third-party/tgfx/pins.json`. In clean dependency checkouts at those revisions,
apply the matching cumulative patches:

```sh
git -C /path/to/tgfx apply --index \
  /path/to/Valdi/snap_drawing/experimental/tgfx/full/archive/20261104/vendor/tgfx-current.patch
git -C /path/to/thorvg apply --index \
  /path/to/Valdi/snap_drawing/experimental/tgfx/full/archive/20261104/vendor/thorvg-current.patch
```

`--index` makes newly added dependency files visible to the preparation tools'
tracked-source snapshot. The patch manifest records the complete current
working-tree diffs against the pins, including the Android RTTI opt-in; earlier
per-platform receipts may record an earlier patch identity.

Follow `third-party/tgfx/README.md` to acquire the pinned transitive sources,
build matching dependency archives, and prepare the required profiles.
Prepared archives, SDKs, build caches, temporary logs, local signing material,
and installed APK/app artifacts are not part of this branch. Matching headers
and archives must be rebuilt together; the branch is a source archive, not a
prebuilt runtime release.
